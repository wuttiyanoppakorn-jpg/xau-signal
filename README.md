# 🥇 XAU/USD Gold Signal — กราฟทองคำเรียลไทม์ + สัญญาณ Buy/Sell

เว็บกราฟทองคำแบบเรียลไทม์ (แท่งเทียน M1/M5/M15/H1/H4) พร้อมสัญญาณ **BUY / SELL** ขึ้นตรงแท่งเทียน วิเคราะห์อัตโนมัติในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร

🔗 **เปิดใช้งาน:** https://wuttiyanoppakorn-jpg.github.io/xau-signal/

## ฟีเจอร์
- **กราฟสด** ผ่าน WebSocket (อัปเดตทุกครั้งที่ราคาขยับ) เวลาไทย (UTC+7)
- **สัญญาณ 2 ขั้น**
  - ⏳ **เตรียมเข้า** — ขึ้นทันทีระหว่างแท่งเทียนยังไม่ปิด (วงกลมจาง) ถ้าเงื่อนไขหายเกิน 8 วินาทีหรือแท่งปิดไม่ผ่านเกณฑ์ จะเปลี่ยนเป็น **ยกเลิก** (สีเทา) พร้อมเหตุผลและเวลา — การ์ดไม่หายไป
  - ✅ **ยืนยัน** — ยืนยันเมื่อแท่งเทียนปิด (ลูกศรทึบ) ไม่ถูกวาดใหม่ภายหลัง
- **คะแนนความมั่นใจ (%)** จากการรวมหลายวิธี: เทรนด์หลายไทม์เฟรม (M1/M5/M15/H1/H4), EMA 9/20/50/200, RSI + Divergence, MACD, Stochastic RSI, Bollinger Bands (Squeeze/Breakout), ADX, VWAP, ATR, แนวรับ-แนวต้าน + Pivot Points, รูปแบบแท่งเทียน (Engulfing, Pin bar, Inside bar), โครงสร้างตลาด (HH/HL, Break of Structure), Volume
- ปรับ **ความมั่นใจขั้นต่ำ** ได้ด้วยแถบเลื่อน · บอกว่าเป็นไม้ **เก็บสั้นๆ** หรือ **ถือยาว** (ตามเทรนด์ H1 + H4) พร้อมจุดเข้า SL TP
- 🔔 เสียง + การแจ้งเตือนของเบราว์เซอร์ (กดปุ่ม "เปิดแจ้งเตือน")
- 📊 บันทึกทุกสัญญาณในเบราว์เซอร์ (localStorage) พร้อมผลลัพธ์ TP/SL สถิติ Win rate ตามประเภทและตามระดับความมั่นใจ และ **Export CSV**

## มุมมองกราฟ
- **กราฟ OANDA (TradingView)** — ค่าเริ่มต้น ราคา OANDA:XAUUSD จาก widget สาธารณะของ TradingView (ใกล้เคียง Exness MT5) พร้อมกล่อง "สัญญาณล่าสุด" ที่แปลงเป็นราคาแบบ Spot
  - ระบบอ่านแท่งเทียนจาก widget ไม่ได้ (เป็น iframe ของ TradingView) จึงไม่มีลูกศรบนกราฟนี้
  - EXNESS:XAUUSD ไม่มีให้ใช้ใน widget ของ TradingView
- **กราฟสัญญาณ + ลูกศร** — กราฟที่ระบบใช้คำนวณสัญญาณ (XAUT/PAXG) พร้อมลูกศร Buy/Sell, จุดเตรียมเข้า/ยกเลิก และ ★ สัญญาณจากแชท

## สัญญาณจากแชท
- ไฟล์ `signals.json` ในรีโปนี้ หน้าเว็บโหลดใหม่ทุก ~60 วินาที แสดงเป็นจุด ★ บนกราฟสัญญาณ และแท็บ "★ จากแชท" พร้อมสถานะ TP/SL สด
- อัปเดตด้วย `python3 tools/publish_signals.py` (แปลงจาก sent.json แล้ว commit + push เฉพาะเมื่อมีการเปลี่ยนแปลง)

## แหล่งข้อมูล
- กราฟ: **XAUT/USDT (Tether Gold)** จาก Bybit → ถ้าใช้ไม่ได้สลับไป OKX → **PAXG/USDT** จาก Binance อัตโนมัติ (โทเคนที่มีทองคำแท้หนุน 1 โทเคน = 1 ออนซ์)
- ราคา Spot XAU/USD อ้างอิง: gold-api.com (ทุก 15 วินาที) พร้อมแสดงส่วนต่าง และแปลงจุดเข้า/SL/TP เป็นราคา ≈ Spot/MT5
- ราคาอาจต่างจากโบรกเกอร์ (MT5) เล็กน้อย — XAUT มักต่างจาก Spot ราว 0–3 ดอลลาร์, PAXG ราว +8 ดอลลาร์

## ผลทดสอบย้อนหลัง (สรุปตรงๆ)
**รอบใหญ่ (ต.ค. 2026):** ใช้ข้อมูลจริง PAXG M5 ตั้งแต่ ส.ค. 2020 ถึง ต.ค. 2026 (642,101 แท่ง จาก Binance) และ XAUT M5 ตั้งแต่ เม.ย. 2025 ถึง ต.ค. 2026 (156,801 แท่ง จาก Bybit)
ทดสอบแบบ walk-forward ทีละไตรมาส ทุกอย่างตั้งค่าจากข้อมูลก่อนไตรมาสที่ทดสอบเท่านั้น หักสเปรด $0.25 และถ้าแท่งเดียวโดนทั้ง SL และ TP นับเป็น SL ดู `backtest/RESULTS.md`
- Engine ปัจจุบัน (เกณฑ์ 60%): ก่อนหักต้นทุนใกล้เสมอตัว **หลังหักสเปรดติดลบในไตรมาสส่วนใหญ่** (PAXG 2024Q3+ −0.03R/ไม้, XAUT +0.02R/ไม้ บวกแค่ 2 จาก 5 ไตรมาส)
- ลองแล้ว: ปรับเกณฑ์ 50–80, ฟิลเตอร์ H4, ช่วงเวลา, SL/TP 13 แบบ, ปรับพารามิเตอร์ใหม่ทุกไตรมาส 1,248 แบบ, Logistic Regression, LightGBM
- โมเดล ML ที่ดีที่สุดได้ราว +0.03–0.07R/ไม้ แต่ในช่วงข้อมูลล่าสุด**ไม่ได้ชนะ engine เดิมอย่างสม่ำเสมอ** (ชนะ 3 จาก 7 ไตรมาสล่าสุด) จึง**ไม่นำมาใช้**
- สิ่งเดียวที่ดีกว่าแบบสม่ำเสมอคือช่วงเวลา **19:00–23:00 น. (London/NY)**: ชนะการเทรดทั้งวันใน 17/20, 8/10 และ 5/5 ไตรมาส จึงเพิ่มป้าย 🕖 “ช่วงดี” และปุ่ม “เฉพาะ 19:00–23:00 น.” ให้เลือกเปิดเอง (ปิดไว้เป็นค่าเริ่มต้น) — **ยังไม่ใช่ความได้เปรียบที่พิสูจน์แล้ว**
