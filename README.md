# 🥇 XAU/USD Gold Signal — กราฟทองคำเรียลไทม์ + สัญญาณ Buy/Sell

เว็บกราฟทองคำแบบเรียลไทม์ (แท่งเทียน M1/M5/M15/H1/H4) พร้อมสัญญาณ **BUY / SELL** ขึ้นตรงแท่งเทียน วิเคราะห์อัตโนมัติในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร

🔗 **เปิดใช้งาน:** https://wuttiyanoppakorn-jpg.github.io/xau-signal/

## ฟีเจอร์
- **กราฟสด** ผ่าน WebSocket (อัปเดตทุกครั้งที่ราคาขยับ) เวลาไทย (UTC+7)
- **สัญญาณ 2 ขั้น**
  - ⏳ **เตรียมเข้า** — ขึ้นทันทีระหว่างแท่งเทียนยังไม่ปิด (วงกลมจาง) อาจหายไปถ้าเงื่อนไขไม่ครบตอนปิดแท่ง
  - ✅ **ยืนยัน** — ยืนยันเมื่อแท่งเทียนปิด (ลูกศรทึบ) ไม่ถูกวาดใหม่ภายหลัง
- **คะแนนความมั่นใจ (%)** จากการรวมหลายวิธี: เทรนด์หลายไทม์เฟรม (M1/M5/M15/H1/H4), EMA 9/20/50/200, RSI + Divergence, MACD, Stochastic RSI, Bollinger Bands (Squeeze/Breakout), ADX, VWAP, ATR, แนวรับ-แนวต้าน + Pivot Points, รูปแบบแท่งเทียน (Engulfing, Pin bar, Inside bar), โครงสร้างตลาด (HH/HL, Break of Structure), Volume
- ปรับ **ความมั่นใจขั้นต่ำ** ได้ด้วยแถบเลื่อน · บอกว่าเป็นไม้ **เก็บสั้นๆ** หรือ **ถือยาว** (ตามเทรนด์ H1 + H4) พร้อมจุดเข้า SL TP
- 🔔 เสียง + การแจ้งเตือนของเบราว์เซอร์ (กดปุ่ม "เปิดแจ้งเตือน")
- 📊 บันทึกทุกสัญญาณในเบราว์เซอร์ (localStorage) พร้อมผลลัพธ์ TP/SL สถิติ Win rate ตามประเภทและตามระดับความมั่นใจ และ **Export CSV**

## แหล่งข้อมูล
- กราฟ: **XAUT/USDT (Tether Gold)** จาก Bybit → ถ้าใช้ไม่ได้สลับไป OKX → **PAXG/USDT** จาก Binance อัตโนมัติ (โทเคนที่มีทองคำแท้หนุน 1 โทเคน = 1 ออนซ์)
- ราคา Spot XAU/USD อ้างอิง: gold-api.com (ทุก 15 วินาที) พร้อมแสดงส่วนต่าง และแปลงจุดเข้า/SL/TP เป็นราคา ≈ Spot/MT5
- ราคาอาจต่างจากโบรกเกอร์ (MT5) เล็กน้อย — XAUT มักต่างจาก Spot ราว 0–3 ดอลลาร์, PAXG ราว +8 ดอลลาร์

## ผลทดสอบย้อนหลัง (สรุปตรงๆ)
ทดสอบบนข้อมูลจริง ~6 สัปดาห์ (ส.ค.–ต.ค. 2026) แบ่ง 60% แรกไว้ตั้งค่า และ 40% หลังไว้ทดสอบ (ไม่ได้ใช้ตั้งค่า) ดู `backtest/RESULTS.md`
- Win rate ราว 31–37% ที่ RR 1:1.5 / 1:2.5 · ก่อนหักต้นทุนใกล้เสมอตัวถึงบวกเล็กน้อย **หลังหักสเปรด ~$0.30/ไม้ ส่วนใหญ่ติดลบเล็กน้อย**
- คะแนนความมั่นใจที่สูงขึ้น **ไม่ได้** ทำให้ผลดีขึ้นอย่างมีนัยสำคัญ
- **ยังไม่พบความได้เปรียบที่ชัดเจน** — ใช้เป็นเครื่องมือช่วยดูกราฟ ไม่ใช่ระบบเทรดอัตโนมัติ

> ⚠️ ไม่ใช่คำแนะนำการลงทุน ไม่รับประกันกำไร ใช้ Stop Loss ทุกครั้ง
